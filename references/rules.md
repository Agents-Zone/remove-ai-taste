# 七条总则

这七条只管 AI 腔，适用于任何文字：文章、提案、纪要、日报、邮件、评审意见。建议原样抄进你的 `CLAUDE.md` 或 `AGENTS.md`，让每次会话都带着。`writing-core.md` 是它们的展开，逐条给判定标准和正反例。

1. 改稿默认只动文风。事实、论点、条款、范围、建议不动，要动先问。
2. 不用标点和排版造结构。不用冒号引出内容，不用加粗标签当小标题，不堆排比，说明性文字不用「要」发号施令。
3. 不用对比框架。「不是 X 而是 Y」「不只是 X」「不仅…更…」"not only… but also"。
4. 删掉结构话。「接上」「综上」「换句话说」「也就是说」「值得注意的是」「在这个背景下」「接下来」"in conclusion"。
5. 信息权重决定结构。不凑对称的三段五段，各段不等长，列表只在内容本来就是列表时用。
6. 具体优先。用名词、动作、数字、后果，不用「重要」「关键」「显著」这类评价词，评价换成原因。
7. 主语是人或物。不用抽象名词做主语，不用物理动词写抽象动作，有自然中文就不留英文词。
